# แบบทดสอบ (Personality Quiz)

เว็บตอบคำถาม ผลลัพธ์กี่แบบก็ได้ คำถามกี่ข้อก็ได้ แต่ละข้อมีตัวเลือกกี่ตัวก็ได้
แต่ละตัวเลือกให้คะแนนกับผลลัพธ์หนึ่ง ตอนจบผลลัพธ์ที่ถูกเลือกมากสุดจะแสดงพร้อม **รูปภาพ**
เป็นเว็บ static ล้วน ไม่มี database ไม่เก็บข้อมูลผู้เล่น — deploy บน Vercel ได้เลย

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าทำแบบทดสอบ (หน้าหลักที่ผู้ใช้เข้า)
- `admin.html` — หน้าแอดมิน แก้คำถาม/ผลลัพธ์
- `config.js` — ไฟล์เก็บคำถามและข้อความผลลัพธ์
- `vercel.json` — ตั้งค่า Vercel

## วิธี deploy บน Vercel

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (หรือลากทั้งโฟลเดอร์เข้า vercel.com ก็ได้)
2. ที่ Vercel กด **Add New → Project** เลือก repo นี้
3. Framework Preset เลือก **Other** (ไม่ต้องตั้ง build command)
4. กด **Deploy** เสร็จ

ผู้ใช้เข้าที่ `https://your-app.vercel.app/` = หน้าแบบทดสอบ
แอดมินเข้าที่ `https://your-app.vercel.app/admin` = หน้าตั้งค่า

## วิธีแก้คำถาม/ผลลัพธ์ (สำหรับแอดมิน) — วิธีที่ง่ายที่สุด ✅

ไม่ต้อง deploy ใหม่ ไม่ต้องยุ่งกับโค้ด:

1. เปิดหน้า `/admin`
2. ตั้งค่า:
   - **ผลลัพธ์**: เพิ่ม/ลบได้ ใส่ชื่อ คำอธิบาย และ **ลิงก์รูป (URL)**
   - **คำถาม**: เพิ่ม/ลบข้อได้ แต่ละข้อเพิ่ม/ลบตัวเลือกได้ และเลือกว่าตัวเลือกนั้น "ให้คะแนนผลลัพธ์ไหน"
3. กด **🔗 สร้างลิงก์สำหรับส่ง**
4. กด **📋 คัดลอกลิงก์** แล้วเอาลิงก์นั้นส่งให้ผู้ใช้ 100 คน — จบ!

> 🖼️ **เรื่องรูป:** เพราะระบบใช้ "ลิงก์เดียว ไม่มี backend" รูปต้องเป็น URL
> อัปโหลดรูปไว้ที่ imgur / Google Drive (แชร์ public) / Discord ก่อน แล้วเอา URL มาวาง

คำถามและผลลัพธ์ทั้งหมดถูกฝังอยู่ในตัวลิงก์ ผู้ใช้เปิดลิงก์ก็เห็นแบบทดสอบเวอร์ชันที่แอดมินตั้งไว้ทันที
อยากแก้อีก ก็แค่แก้ในหน้า admin แล้วสร้างลิงก์ใหม่ ส่งลิงก์ใหม่แทน (ลิงก์เก่ายังใช้ได้ เป็นเวอร์ชันเดิม)

### (ทางเลือก) เปลี่ยนค่าเริ่มต้นถาวร
ถ้าอยากให้ลิงก์หลัก `/` (ไม่มี `?c=`) เป็นเวอร์ชันใหม่เลย ให้กด **⬇️ ดาวน์โหลด config.js**
เอาไฟล์ไปวางทับใน GitHub/โปรเจกต์ แล้ว Vercel จะ deploy ใหม่ให้เอง — อันนี้เป็นทางเลือก ไม่จำเป็น

## ลำดับการอ่านค่าของหน้าแบบทดสอบ

1. ถ้าลิงก์มี `?c=...` → ใช้ค่าจากในลิงก์ (วิธีหลักของแอดมิน)
2. ถ้าเปิดจากหน้า admin ในเครื่องเดียวกัน → ใช้ค่าพรีวิวที่บันทึกไว้
3. ไม่งั้น → ใช้ค่าเริ่มต้นจาก `config.js`

## กติกาการตัดสินผล

- นับว่าแต่ละผลลัพธ์ถูกเลือกกี่ครั้ง (จากตัวเลือกที่ผู้ใช้กด)
- ผลลัพธ์ที่ถูกเลือกมากที่สุด = ผลลัพธ์ที่แสดง (พร้อมรูป)
- ถ้าเสมอกัน → แสดงผลลัพธ์ที่อยู่ลำดับก่อนในรายการผลลัพธ์

## ทดสอบในเครื่องก่อน deploy

เปิด terminal ในโฟลเดอร์นี้แล้วรัน:

```
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000` (ต้องรันผ่าน server ไม่ใช่เปิดไฟล์ตรง ๆ เพราะ admin ใช้ localStorage)
